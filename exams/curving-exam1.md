# Curving for Exam 1

Scores between 60 and 80 went up by about 4 percent. Outside that range, the increase is interpolated using a straight line so that zero remains at zero and 100 remains at 100.

| Raw score | Curved score |
|---|---:|
| 0% | 0.0% |
| 10% | 10.7% |
| 20% | 21.4% |
| 30% | 32.1% |
| 40% | 42.9% |
| 50% | 53.6% |
| 60% | 64.0% |
| 70% | 74.0% |
| 80% | 84.0% |
| 90% | 92.0% |
| 100% | 100.0% |
